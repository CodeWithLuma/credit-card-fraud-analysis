# Data source

The dataset is **not** included in this repo.

- **Dataset:** Credit Card Fraud Detection
- **Get it here:** https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
- **File to download:** `creditcard.csv`
- **Put it here:** `data/creditcard.csv`

## About the file

- Collected by Worldline and the Machine Learning Group of Université Libre
  de Bruxelles (ULB).
- Transactions made by European cardholders in September 2013, over two days.
- 284,807 transactions, 492 of them fraudulent (0.172%).
- 31 columns: `Time`, `V1`–`V28` (PCA transformation), `Amount`, `Class`
  (1 = fraud, 0 = legitimate).
- You need a free Kaggle account to download it.
